# VIA Biler Landingpage – fælleskodning

I denne opgave bygger vi sammen en responsiv landingpage for **VIA Biler** ved hjælp af HTML og CSS.

Under fælleskodningen skal du indsætte kode i de markerede områder i starterfilerne. Vi gemmer og undersøger løbende resultatet i browseren.

Du kommer blandt andet til at arbejde med:

- semantisk HTML
- et eksternt stylesheet
- CSS-variabler
- Flexbox
- baggrundsbillede og hero-sektion
- enkel responsiv tilpasning

## Projektets filer

| Fil | Indhold |
| --- | --- |
| `index.html` | Sidens HTML-struktur og indhold |
| `css/style.css` | Sidens styling, layout og responsive regler |
| `link.txt` | Link til det billede, der skal bruges som baggrund i CSS |

> Du skal arbejde videre i de eksisterende filer. Du skal ikke oprette et nyt projekt eller nye HTML- og CSS-filer.

## Fremgangsmåde

Følg punkterne ét ad gangen og i den viste rækkefølge.

Du skal først oprette dit eget repository fra skabelonen på GitHub.com. Derefter skal du hente dit repository ned på computeren med GitHub Desktop og åbne projektet i Visual Studio Code.

### 1. Opret dit eget repository fra skabelonen

1. Åbn [VIA Biler Landingpage – template](https://github.com/muratkilic1978/via-biler-landingpage).
2. Kontrollér, at du er logget ind på din egen GitHub-konto.
3. Klik på den grønne knap **Use this template**.
4. Vælg **Create a new repository**.
5. Kontrollér, at din egen GitHub-konto er valgt under **Owner**.
6. Skriv følgende i feltet **Repository name**:

   ```text
   via-biler-landingpage
   ```

7. Vælg den synlighed, som din underviser har oplyst.
8. Klik på **Create repository from template**.

Når repositoryet er oprettet, skal dit eget GitHub-brugernavn stå foran navnet. Det kan eksempelvis se sådan ud:

```text
dit-brugernavn/via-biler-landingpage
```

> Stop her, og kontrollér, at du befinder dig i dit eget repository, før du fortsætter.

### 2. Hent repositoryet ned på din computer

1. Sørg for, at du er inde på dit eget repository på GitHub.com.
2. Klik på den grønne knap **Code**.
3. Kopiér repositoryets HTTPS-adresse.
4. Åbn **GitHub Desktop**.
5. Vælg **File → Clone Repository...**.
6. Vælg fanebladet **URL**.
7. Indsæt adressen i feltet **Repository URL**.
8. Vælg under **Local Path**, hvor projektet skal gemmes på computeren.
9. Klik på **Clone**.

GitHub Desktop opretter nu en lokal kopi af dit repository på computeren.

### 3. Åbn projektet i Visual Studio Code

Vælg i GitHub Desktop:

**Repository → Open in Visual Studio Code**

Knappen kan også hedde **Open in default editor**, hvis Visual Studio Code allerede er valgt som standardeditor.

Kontrollér i Visual Studio Code, at du kan se:

- `index.html`
- mappen `css` med filen `style.css`
- `link.txt`

### 4. Lav løbende commits under fælleskodningen

Når vi har færdiggjort en naturlig del af koden, laver vi et commit sammen:

1. Gem dine ændringer i Visual Studio Code.
2. Gå tilbage til GitHub Desktop, og kontrollér ændringerne under **Changes**.
3. Skriv en kort og meningsfuld commitbesked i feltet **Summary**.
4. Klik på **Commit to main**.
5. Klik på **Push origin**, så dit commit bliver sendt til GitHub.com.

Eksempler på commitbeskeder:

```text
Tilføj HTML-struktur og navigation
Tilføj Flexbox til headeren
Tilføj hero-sektion og responsivt layout
```

## Vores arbejdsgang

```text
Indsæt kode → Gem → Se resultatet i browseren → Commit → Push
```
